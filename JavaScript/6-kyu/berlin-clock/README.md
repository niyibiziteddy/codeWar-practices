<h2><a href=https://www.codewars.com/kata/5a1463678ba9145a670000f9/train/javascript target="_blank">Berlin Clock</a></h2><h3>6 kyu</h3><p>The <em>"Berlin Clock"</em> is the first public clock in the world that tells the time by means of illuminated, coloured fields, for which it entered the Guinness Book of Records upon its installation on 17 June 1975. </p><div style="max-width: 300px; margin: auto; background: #bbb;border: 20px solid #bbb"><p><img alt="alt text" src="https://upload.wikimedia.org/wikipedia/commons/4/4f/Berlin-Uhr-1650-1705.gif"></p></div><p>The clock is read from the top row to the bottom:</p><ul><li>the round <strong>Y</strong>ellow light on top blinks to denote even- (when on) or odd-numbered (off) seconds,</li><li>the first row of four <strong>R</strong>ed fields denote five full hours each,</li><li>the second row, also of four <strong>R</strong>ed fields, which denote one full hour each (displaying the hour value in 24-hour format)</li><li>the third row consists of eleven <strong>Y</strong>ellow-and-<strong>R</strong>ed fields, which denote five full minutes each (the red ones also denoting 15, 30 and 45 minutes past),</li><li>the bottom row has another four <strong>Y</strong>ellow fields, which mark one full minute each.</li></ul><p><em>For example:</em></p><p>Two fields are lit in the first row (2 x 5 = 10), but no fields are lit in the second row (0); therefore the hour value is 10. Six fields are lit in the third row (6 x 5 = 30), while the bottom row has one field on (1). Hence, the lights of the clock altogether tell the time as 10:31 (<a href="https://en.wikipedia.org/wiki/Mengenlehreuhr" data-turbolinks="false" target="_blank">Source: Wikipedia</a>)</p><h2 id="task">Task</h2><p>Complete the function that takes a particular time in 24h format (<code>"hh:mm:ss"</code>) and outputs a string that reproduces the Berlin Clock.
