<h2><a href=https://www.codewars.com/kata/578bf2d8daa01a4ee8000046/train/javascript/6a829a777b594d3ee00d10db target="_blank">Data compression using run-length encoding</a></h2><h3>6 kyu</h3><p><a href="http://en.wikipedia.org/wiki/Run-length_encoding" data-turbolinks="false" target="_blank">Run-length encoding</a> (RLE) is a very simple form of lossless data compression in which runs of data are stored as a single data value and count.</p><p>A simple form of RLE would encode the string <code>"AAABBBCCCD"</code> as <code>"3A3B3C1D"</code> meaning, first there are <code>3 A</code>, then <code>3 B</code>, then <code>3 C</code> and last there is <code>1 D</code>.</p><p>Your task is to write a RLE encoder and decoder using this technique. The texts to encode will always consist of only uppercase characters, no numbers.</p>
